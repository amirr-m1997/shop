Please fix the scroll restoration issue only in specific sections of the website.

## Problem:

The scroll position issue does NOT happen everywhere.

It only happens in these sections:

1. Daily Trends section
2. Categories section
3. The two middle graphic/product cards on the homepage

When a user scrolls in these sections, clicks on a product card, enters the product detail page, and then comes back using the browser Back button, the user is returned to the top of the page instead of the exact previous position.

Example:

User is on homepage:

```
/
```

User scrolls down to:

```
Daily Trends section
scroll position: 1800px
```

User clicks a product:

```
/product/product-name
```

User clicks Back.

Expected:

* Return to homepage
* Restore exactly the previous scroll position
* User should see the same product card area where they left

Current:

* Homepage loads from the top
* User loses their browsing position

---

Only investigate and fix:

* Daily Trends component
